# 安装说明

## 安装

Gitee源（国内首推）
```bash
git clone https://gitee.com/q1638276310/sp-plugin.git ./plugins/sp-plugin/
```

Github源（国外推荐）
```bash
git clone https://github.com/1638276310/sp-plugin.git ./plugins/sp-plugin/
```

SSH源（需配置SSH密钥）
```bash
git clone git@gitee.com:q1638276310/sp-plugin.git ./plugin/sp-plugin/   #Gitee SSH
git clone git@github.com:1638276310/sp-plugin.git ./plugin/sp-plugin/   #GitHub SSH
```

## 安装依赖

```bash
pnpm i --filter=sp-plugin
```
