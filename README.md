# 安装说明

## 安装

```bash
git clone https://ghfast.top/https://github.com/1638276310/sp-plugin.git ./plugins/sp-plugin/
```

## 安装依赖

```bash
pnpm i--filter=sp-plugin
```

### 为防止风控，所以安装Python来处理图片

```text
sudo apt install python3-pillow
```
